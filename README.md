# StudyCircle - Full Stack Educational Website

StudyCircle is a responsive full-stack educational website developed for a coaching institute. The project provides information about various courses and allows students to register online and send enquiries through a contact form. It was originally created as a frontend college project and later enhanced with PHP, MySQL, improved UI, and live deployment.

## Live Website
https://studycircle-simran.infinityfreeapp.com

## Project Overview

The website is designed to simulate the online presence of an educational coaching institute. It offers a modern user interface along with backend functionality for handling student registrations and contact messages using a MySQL database.

## Installation

1. Clone this repository
git clone https://github.com/simran84debug/StudyCircle-FullStackWebsite.git

2. Copy the project folder to the **htdocs** directory of XAMPP.

3. Start **Apache** and **MySQL** using XAMPP.

4. Create a MySQL database.

5. Import the required database tables.

6. Rename **db.example.php** to **db.php** and update your database credentials.

7. Open the project in your browser:
http://localhost/StudyCircle
